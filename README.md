# 2026 물리보안 캠페인 DID

현대자동차 물리보안 캠페인 부스에 설치되는 세로형 DID(디지털 사이니지) 화면.

## 화면 순서

1. **시작 화면** — `배경_첫화면.png` + `버튼_마지막 화면.png`(참여 시작하기)
2. **영상** — `0904.mp4`
3. **완료 화면** — `배경_마지막 화면.png` + `효과_아래서 위로.png` + `효과_완료.png` + `버튼_첫화면.png`(처음으로)

터치가 안 되는 화면에서도 쓸 수 있도록 기본이 자동 순환이다.
시작 화면(8초) → 영상 → 완료 화면(12초) → 다시 시작 화면으로 계속 반복된다.
버튼을 누르면(터치 또는 마우스) 기다리지 않고 바로 넘어간다.
'처음으로'를 누르면 다시 시작 화면으로 돌아간다.

## 동작 방식

- 원본 이미지 비율(2161 × 3841)의 스테이지를 만들고 모든 요소를 %로 배치하므로,
  어떤 해상도의 세로형 화면에서도 동일한 레이아웃으로 나온다.
- 영상은 `index.html` 의 `VIDEOS` 배열로 관리한다. 여러 편을 넣으면 순서대로 이어서 재생되며,
  플레이어 2개를 번갈아 사용하므로 전환 시 검은 화면이나 끊김이 없다.
  영상 파일이 없거나 재생이 불가능하면 자동으로 다음 순서로 넘어간다.
- 완료 화면의 뱃지는 앞면·뒷면과 96개의 옆면 판으로 이루어진 3D 코인이며,
  세로축을 기준으로 한 바퀴 회전한 뒤 정면에서 멈춘다.

## 수정 시 참고

| 대상 | 위치 |
|---|---|
| 자동 순환 켜기/끄기, 화면별 대기 시간 | `index.html` 의 `AUTO` 설정 |
| 영상 목록 | `index.html` 의 `VIDEOS` 배열 |
| 뱃지 두께 | `#fx-done` 의 `--half` (기본 `3.9em`) |
| 뱃지 회전 속도 | `#screen-final.play #fx-done .coin` 의 `animation` 값 |
| 버튼 위치 | `.btn` 의 `left` / `top` / `width` |

이미지 파일을 교체할 때는 파일명과 캔버스 크기(2161 × 3841)를 그대로 유지하면 코드 수정 없이 반영된다.

## 현장 설치 (USB + 미니 PC)

이 폴더를 통째로 USB에 복사해 미니 PC에 꽂고 `시작.bat` 을 실행하면
Chrome이 전체 화면 키오스크 모드로 뜬다. 자세한 순서는 `사용안내.txt` 참고.

영상이 재생되지 않거나 끝나지 않는 경우에도 감시 타이머가 다음 순서로 넘겨주므로,
무인 운영 중 화면이 멈춰 있는 일이 없다.

## 배포

빌드 과정이 없는 정적 사이트다. Netlify에 이 저장소를 연결하면 `main` 브랜치에 push할 때마다 자동으로 재배포된다.
