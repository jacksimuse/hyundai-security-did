# 2026 물리보안 캠페인 DID

현대자동차 물리보안 캠페인 부스에 설치되는 세로형 DID(디지털 사이니지) 화면.

## 화면 순서

1. **시작 화면** — `배경_첫화면.png` + `버튼_마지막 화면.png`(참여 시작하기)
2. **영상** — 후보 3편 중 1편을 무작위로 재생
3. **완료 화면** — `배경_마지막 화면.png` + `효과_아래서 위로.png` + `효과_완료.png` + `버튼_첫화면.png`(처음으로)

터치 키오스크에 설치되므로 방문객이 버튼을 눌러 진행한다.
[참여 시작하기] → 영상 → (끝나면 자동으로) 완료 화면 → [처음으로] → 시작 화면.

터치가 안 되는 화면에 쓸 일이 생기면 `AUTO.enabled` 를 `true` 로 바꾸면
버튼 없이 자동으로 순환한다.

## 두 가지 버전과 영상 후보

| 버전 | 페이지 | 영상 후보 (이 중 1편 무작위) |
|---|---|---|
| 공장 | `index.html` | 1차 쇼츠 공장RE2 · 2차 쇼츠 RE3 · 3차 쇼츠 RE2 |
| 연구소 | `lab.html` | 1차 쇼츠 연구소RE2 · 2차 쇼츠 RE3 · 3차 쇼츠 RE2 |

1차 쇼츠만 공장용/연구소용이 다르고 2차·3차는 공통이다.
두 페이지는 영상 후보 목록과 제목만 다르고 나머지는 동일하다.

## 동작 방식

- 원본 이미지 비율(2161 × 3841)의 스테이지를 만들고 모든 요소를 %로 배치하므로,
  어떤 해상도의 세로형 화면에서도 동일한 레이아웃으로 나온다.
- 영상 후보는 `VIDEO_POOL` 배열로 관리한다. 화면이 열릴 때와 [처음으로]를 누를 때마다
  다음에 틀 영상을 무작위로 하나 고르고, **직전에 나온 영상은 후보에서 뺀다**
  (같은 영상이 연달아 나오지 않음).
- 고른 한 편만 미리 준비해 두므로, 버튼을 누르면 검은 화면 없이 바로 재생되고
  메모리에는 항상 영상 하나만 올라간다 (저사양 키오스크 대응).
- 영상 파일이 없거나 재생이 불가능하면 감시 타이머가 완료 화면으로 넘겨주므로
  무인 운영 중 화면이 멈춰 있는 일이 없다.
- 완료 화면의 뱃지는 앞면·뒷면과 96개의 옆면 판으로 이루어진 3D 코인이며,
  세로축을 기준으로 한 바퀴 회전한 뒤 정면에서 멈춘다.

## 수정 시 참고

| 대상 | 위치 |
|---|---|
| 영상 후보 목록 | `VIDEO_POOL` 배열 |
| 자동 순환(터치 없는 화면용) 켜기/끄기 | `AUTO` 설정 |
| 뱃지 두께 | `#fx-done` 의 `--half` (기본 `3.9em`) |
| 뱃지 회전 속도 | `#screen-final.play #fx-done .coin` 의 `animation` 값 |
| 버튼 위치 | `.btn` 의 `left` / `top` / `width` |

## 영상 파일

저장소의 영상은 웹 배포용 압축본(720×1280, 각 1.3~2.0MB)이다.
현장 키오스크에는 원본(1080×1920, 각 25~40MB)을 쓴다 — 파일명이 같으므로
HTML은 양쪽 모두 수정 없이 동작한다.

## 현장 설치

DID_USB 폴더를 키오스크 PC에 복사하고 `index.html`(공장) 또는 `lab.html`(연구소)을
Chrome으로 연 뒤 F11로 전체 화면. 자세한 내용은 `사용안내.txt` 참고.

## 배포

빌드 과정이 없는 정적 사이트다. Netlify가 이 저장소의 `main` 브랜치에 연결되어 있어
push할 때마다 자동으로 재배포된다.
