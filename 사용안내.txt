2026 현대자동차 물리보안 캠페인 DID — 사용 안내
====================================================

■ 실행 방법

  1. DID_USB 폴더를 통째로 키오스크 PC 바탕화면에 복사합니다.
     (USB에서 바로 실행해도 되지만, 복사해서 쓰는 쪽이 끊김이 적습니다)
  2. 틀고 싶은 버전의 파일을 더블클릭합니다.

         공장 버전    →   index.html
         연구소 버전  →   lab.html

  3. 브라우저가 열리면 F11 을 눌러 전체 화면으로 만듭니다.

  ● 전체 화면 끄기  : F11
  ● 브라우저 닫기   : Alt + F4

  ※ Chrome 으로 여는 것을 권장합니다. 키오스크 PC에 Chrome이 없으면
    폴더 안의 ChromeSetup 파일로 설치하세요.
    html 파일이 다른 브라우저로 열리면:
    html 파일에서 오른쪽 클릭 → 연결 프로그램 → Chrome


■ 화면 진행

      시작 화면
          ↓   방문객이 [참여 시작하기] 를 누름
      영상 — 3편 중 1편이 무작위로 재생 (40초 ~ 1분)
          ↓   영상이 끝나면 자동으로
      완료 화면
          ↓   [처음으로] 를 누름
      다시 시작 화면

  직전에 나온 영상은 다음 차례에서 빠지므로, 같은 영상이 연달아
  나오지 않습니다.

■ 영상을 바꾸거나 늘릴 때

  1. 새 영상 파일을 이 폴더(html 파일과 같은 곳)에 넣습니다.
  2. html 파일을 메모장으로 열고 아래 목록의 파일명을 고칩니다.

       const VIDEO_POOL = [
         '첫번째 영상.mp4',
         '두번째 영상.mp4',
         '세번째 영상.mp4'
       ];

     줄을 추가하면 후보가 늘어나고, 빼면 줄어듭니다.
     한 편만 남기면 항상 그 영상만 재생됩니다.

  세로 1080 x 1920 영상이면 화면에 여백 없이 꽉 찹니다.


■ 영상이 끊기거나 멈출 때

  1. Chrome 주소창에 chrome://settings/system 입력
     → "가능한 경우 그래픽 가속 사용" 이 켜져 있는지 확인
     (꺼져 있었다면 켜고 Chrome을 완전히 껐다 다시 켭니다)

  2. 키오스크에서 다른 프로그램은 모두 끄고 브라우저 창 하나만 띄웁니다.

  3. 하루 종일 켜두는 경우, 중간에 한 번씩 브라우저를 껐다 켜주세요.

  4. Windows 전원 설정에서 화면 끄기·절전을 "안 함" 으로 둡니다.


■ 터치가 안 되는 화면에 쓸 때

  버튼을 누를 사람이 없으므로 자동으로 순환하게 바꿀 수 있습니다.
  html 파일을 메모장으로 열고 위쪽의 이 부분을 고칩니다.

       const AUTO = {
         enabled:   false,     ← true 로 바꾸면 자동 순환
         startHold:  8000,     ← 시작 화면을 보여주는 시간 (밀리초)
         finalHold: 12000      ← 완료 화면을 보여주는 시간 (밀리초)
       };
