2026 물리보안 캠페인 DID — 현장 설치 안내
==========================================

■ 두 가지 버전이 들어 있습니다

  공장 버전   →  시작_공장VER.bat   (index.html + 0930_..._공장VER.mp4)
  연구소 버전 →  시작_연구소VER.bat (lab.html   + 0930_..._연구소VER.mp4)

  틀고 싶은 쪽의 bat 파일을 더블클릭하면 됩니다.
  한 폴더 안에 둘 다 들어 있으니, 현장에서 필요한 쪽만 실행하시면 됩니다.

■ 준비물
  · USB 메모리 (이 폴더가 약 330MB입니다)
  · 미니 PC(또는 노트북) — Windows, Google Chrome 설치
  · TV와 연결할 HDMI 케이블

■ 설치 순서

  1. 이 폴더(DID_USB) 전체를 USB에 복사합니다.
     ※ 폴더 안의 파일을 따로 빼지 마세요. 같은 폴더에 있어야 동작합니다.

  2. USB를 미니 PC에 꽂고, 미니 PC를 TV에 HDMI로 연결합니다.

  3. 폴더를 열고 시작_공장VER.bat 또는 시작_연구소VER.bat 을 더블클릭합니다.
     전체 화면으로 실행되며, 마우스 커서는 3초 뒤 자동으로 사라집니다.

  4. 종료할 때는 Alt + F4 를 누릅니다.
     다른 버전으로 바꾸려면 종료한 뒤 다른 bat 파일을 실행하면 됩니다.

  ※ USB를 꽂아둔 채로 쓰셔도 되지만, 폴더를 미니 PC의 바탕화면에
     복사해두고 쓰는 쪽이 더 안정적이고 재생도 매끄럽습니다.
     영상이 큰 편이라(각 170MB) 특히 권장합니다.

■ 동작 방식 (터치 없이 자동 순환)

  시작 화면 (8초)  →  영상 (2분 16초)  →  완료 화면 (12초)  →  다시 시작 화면

  버튼을 누르지 않아도 계속 반복됩니다. 한 바퀴에 약 2분 36초 걸립니다.
  무선 마우스가 있으면 버튼을 클릭해 바로 넘길 수도 있습니다.

■ 시간 조절 방법

  index.html(공장) 또는 lab.html(연구소) 을 메모장으로 열고
  위쪽의 이 부분을 고칩니다. 숫자는 밀리초 단위입니다 (1000 = 1초).

      const AUTO = {
        enabled:   true,
        startHold:  8000,   ← 시작 화면을 보여주는 시간
        finalHold: 12000    ← 완료 화면을 보여주는 시간
      };

  터치 모니터를 쓰게 되어 방문객이 직접 누르는 방식으로 바꾸려면
  enabled 를 false 로 바꾸면 됩니다. 그러면 버튼을 눌러야만 넘어갑니다.

■ 영상 교체 방법

  새 영상 파일을 이 폴더에 넣고, 해당 html 파일에서 아래 부분의
  파일명을 새 파일명으로 바꿉니다.

      index.html :  const VIDEOS = ['0930_현대자동차 공장보안_통합쇼츠_공장VER.mp4'];
      lab.html   :  const VIDEOS = ['0930_현대자동차 공장보안_통합쇼츠_연구소VER.mp4'];

  세로 1080 x 1920 비율이면 화면에 여백 없이 꽉 찹니다.
  여러 편을 이어서 틀려면 이렇게 나열하면 됩니다.

      const VIDEOS = ['첫번째.mp4', '두번째.mp4'];

■ 부팅하면 저절로 켜지게 하려면

  1. 키보드에서 윈도우키 + R 을 누르고 shell:startup 을 입력합니다.
  2. 열린 폴더에 실행할 bat 파일의 바로가기를 만들어 넣습니다.
     (bat 파일 오른쪽 클릭 → 복사 → 시작 폴더에서 오른쪽 클릭 →
      "바로 가기 붙여넣기")

  이렇게 하면 미니 PC를 켤 때마다 자동으로 화면이 뜹니다.
  전원 설정에서 절전·화면 끄기를 "안 함" 으로 두면 더 안정적입니다.
  (bat 파일이 실행될 때 자동으로 설정하지만, 직접 확인해두시면 좋습니다.)

■ 소리

  영상에 소리가 들어 있습니다. TV 볼륨으로 조절하시면 됩니다.
  소리를 끄고 싶으면 TV를 음소거하세요.

■ _삭제해도됨 폴더

  이전 버전에서 쓰던 파일입니다. 지우셔도 됩니다.
