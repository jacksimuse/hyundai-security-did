2026 물리보안 캠페인 DID — 현장 설치 안내
==========================================

■ 준비물
  · USB 메모리
  · 미니 PC(또는 노트북) — Windows, Google Chrome 설치
  · TV와 연결할 HDMI 케이블

■ 설치 순서

  1. 이 폴더(DID) 전체를 USB에 복사합니다.
     ※ 폴더 안의 파일을 따로 빼지 마세요. 같은 폴더에 있어야 동작합니다.

  2. USB를 미니 PC에 꽂고, 미니 PC를 TV에 HDMI로 연결합니다.

  3. USB 안의 DID 폴더를 열고 "시작.bat" 을 더블클릭합니다.
     전체 화면으로 실행되며, 마우스 커서는 3초 뒤 자동으로 사라집니다.

  4. 종료할 때는 Alt + F4 를 누릅니다.

  ※ USB를 꽂아둔 채로 쓰셔도 되고, 폴더를 미니 PC의 바탕화면에
     복사해두고 쓰셔도 됩니다. 복사해두는 쪽이 더 안정적입니다.

■ 동작 방식 (터치 없이 자동 순환)

  시작 화면 (8초)  →  영상 재생  →  완료 화면 (12초)  →  다시 시작 화면

  버튼을 누르지 않아도 계속 반복됩니다.
  무선 마우스가 있으면 버튼을 클릭해 바로 넘길 수도 있습니다.

■ 시간 조절 방법

  index.html 을 메모장으로 열고 위쪽의 이 부분을 고칩니다.
  숫자는 밀리초 단위입니다 (1000 = 1초).

      const AUTO = {
        enabled:   true,
        startHold:  8000,   ← 시작 화면을 보여주는 시간
        finalHold: 12000    ← 완료 화면을 보여주는 시간
      };

  터치 모니터를 쓰게 되어 방문객이 직접 누르는 방식으로 바꾸려면
  enabled 를 false 로 바꾸면 됩니다. 그러면 버튼을 눌러야만 넘어갑니다.

■ 영상 교체 방법

  새 영상 파일의 이름을 0904.mp4 로 바꿔 이 폴더의 기존 파일에 덮어씁니다.
  세로 1080 x 1920 비율이면 화면에 여백 없이 꽉 찹니다.

  파일명을 그대로 쓰고 싶으면 index.html 에서 아래 부분을 고칩니다.

      const VIDEOS = ['0904.mp4'];

  여러 편을 넣으려면 이렇게 나열하면 순서대로 이어서 재생됩니다.

      const VIDEOS = ['0904.mp4', '0905.mp4'];

■ 부팅하면 저절로 켜지게 하려면

  1. 키보드에서 윈도우키 + R 을 누르고 shell:startup 을 입력합니다.
  2. 열린 폴더에 "시작.bat" 의 바로가기를 만들어 넣습니다.
     (시작.bat 을 오른쪽 클릭 → 복사 → 시작 폴더에서 오른쪽 클릭 →
      "바로 가기 붙여넣기")

  이렇게 하면 미니 PC를 켤 때마다 자동으로 화면이 뜹니다.
  전원 설정에서 절전·화면 끄기를 "안 함" 으로 두면 더 안정적입니다.
  (시작.bat 이 실행될 때 자동으로 설정하지만, 직접 확인해두시면 좋습니다.)

  영상에 소리가 들어 있습니다. TV 볼륨으로 조절하시면 됩니다.
  소리를 끄고 싶으면 TV를 음소거하세요.
