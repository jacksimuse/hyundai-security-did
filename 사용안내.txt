2026 현대자동차 물리보안 캠페인 DID — 사용 안내
====================================================

■ 실행 방법 (이것만 하시면 됩니다)

  1. USB를 키오스크 PC에 꽂습니다.
  2. USB 안의 DID_USB 폴더를 엽니다.
  3. 틀고 싶은 버전의 파일을 더블클릭합니다.

         공장 버전    →   index.html
         연구소 버전  →   lab.html

  4. 브라우저가 열리면 F11 을 눌러 전체 화면으로 만듭니다.

  ● 전체 화면 끄기  : F11
  ● 브라우저 닫기   : Alt + F4
  ● 다른 버전으로   : 창을 닫고 다른 html 파일을 더블클릭

  ※ 같은 폴더의 시작_공장VER.bat / 시작_연구소VER.bat 을 쓰면
    F11 을 누르지 않아도 처음부터 전체 화면으로 열리고,
    모니터 절전도 자동으로 해제됩니다. 편한 쪽을 쓰시면 됩니다.


■ 화면 진행 (방문객이 터치해서 진행)

      시작 화면
          ↓   방문객이 [참여 시작하기] 를 누름
      영상 (2분 16초)
          ↓   영상이 끝나면 자동으로
      완료 화면
          ↓   [처음으로] 를 누름
      다시 시작 화면

  버튼을 누르기 전에는 시작 화면이 계속 떠 있습니다.
  영상이 끝나면 완료 화면으로는 저절로 넘어갑니다.


■ 처음 한 번만 확인해 주세요

  · 미니 PC에 Google Chrome이 설치되어 있어야 합니다.
    (없으면 Microsoft Edge로 대신 실행됩니다)

  · 영상에 소리가 들어 있습니다. TV 볼륨으로 조절하시면 됩니다.

  · USB를 꽂은 채로 바로 실행해도 되지만, 폴더를 통째로 미니 PC
    바탕화면에 복사해두고 실행하면 더 안정적입니다.
    영상이 큰 편이라(각 163MB) 현장에서는 복사해두길 권합니다.


■ 전원을 켜면 저절로 실행되게 하려면

  1. 키보드에서  윈도우키 + R  을 누릅니다.
  2. shell:startup  을 입력하고 확인을 누릅니다.
  3. 열린 폴더에 실행할 bat 파일의 바로가기를 넣습니다.
     (bat 파일에서 마우스 오른쪽 클릭 → 복사 →
      열린 폴더에서 오른쪽 클릭 → "바로 가기 붙여넣기")

  전원 설정에서 화면 끄기와 절전을 "안 함"으로 두면 더 안정적입니다.
  bat 파일이 실행될 때 자동으로 설정하긴 하지만, 확인해두시면 좋습니다.


■ 폴더 안의 파일

  시작_공장VER.bat      공장 버전 실행
  시작_연구소VER.bat    연구소 버전 실행
  index.html            공장 버전 화면
  lab.html              연구소 버전 화면
  [ARGOS] ..._공장VER_1001.mp4      공장 버전 영상
  [ARGOS] ..._연구소VER_1001.mp4    연구소 버전 영상
  배경_*.png / 버튼_*.png / 효과_*.png    화면 이미지
  HyundaiSans*.ttf      현대 산스 글꼴
  사용안내.txt          이 문서

  ※ 파일을 따로 빼거나 이름을 바꾸지 마세요. 같은 폴더에 그대로 있어야
    동작합니다.


■ 영상을 새 버전으로 바꿀 때

  1. 새 영상 파일을 이 폴더에 넣습니다.
  2. 바꿀 쪽의 html 파일을 메모장으로 열고, 아래 줄의 파일명을
     새 파일명으로 고칩니다.

     index.html (공장)
       const VIDEOS = ['[ARGOS] 현대자동차 물리보안 캠페인_통합쇼츠_공장VER_1001.mp4'];

     lab.html (연구소)
       const VIDEOS = ['[ARGOS] 현대자동차 물리보안 캠페인_통합쇼츠_연구소VER_1001.mp4'];

  세로 1080 x 1920 영상이면 화면에 여백 없이 꽉 찹니다.
  여러 편을 이어서 틀려면 이렇게 나열하면 순서대로 재생됩니다.

       const VIDEOS = ['첫번째.mp4', '두번째.mp4'];


■ 터치가 안 되는 화면에 쓰게 될 때

  터치가 안 되는 TV나 모니터에 틀어야 하면, 버튼을 누를 사람이 없으므로
  자동으로 순환하게 바꿀 수 있습니다.
  html 파일을 메모장으로 열고 위쪽의 이 부분을 고칩니다.

       const AUTO = {
         enabled:   false,     ← true 로 바꾸면 자동 순환
         startHold:  8000,     ← 시작 화면을 보여주는 시간 (밀리초)
         finalHold: 12000      ← 완료 화면을 보여주는 시간 (밀리초)
       };

  true 로 바꾸면 시작 화면 8초 → 영상 → 완료 화면 12초 → 시작 화면 으로
  아무도 누르지 않아도 계속 반복됩니다.
  이때는 소리가 음소거로 나갈 수 있으므로 bat 파일로 실행해야 합니다.


■ 문제가 생기면

  · 화면이 안 뜬다
    → html 파일을 Chrome으로 여는지 확인합니다.
      (html 파일에서 오른쪽 클릭 → 연결 프로그램 → Chrome)

  · 영상이 안 나오고 바로 완료 화면으로 넘어간다
    → 영상 파일명이 html에 적힌 이름과 다른 경우입니다.
      위의 "영상을 새 버전으로 바꿀 때"를 참고해 이름을 맞춰주세요.

  · 영상이 끊긴다
    → 폴더를 미니 PC 바탕화면에 복사한 뒤 거기서 실행해 보세요.

  · 인터넷이 되는 곳이라면 브라우저에서 아래 주소로도 같은 화면을
    볼 수 있습니다. (확인용 / 실제 송출은 위 bat 파일 사용)
